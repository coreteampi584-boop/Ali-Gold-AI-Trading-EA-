Frequently Asked Questions

How much does it cost?

A single license costs $350 USD (one MT5 account). Two licenses cost $600 USD. The package with source code costs $1500 USD.

Can I use one license on multiple MT5 accounts?

No. Each license is valid for one account. The 2-license package covers two accounts.

When will I receive the EA?

After the payment has been manually verified, the EA file and license code will be sent to the Gmail address supplied in the order form.

Does the EA guarantee profit?

No. Trading XAUUSD carries significant risk. Results can vary with market conditions, spreads, commissions, execution, leverage, and broker settings. Only trade money you can afford to lose, and test on a demo account first.

Do I need a VPS?

A VPS is recommended so the EA can run without interruption, but it is not mandatory.

Which broker should I use?

Any MT5 broker that offers a Gold symbol. Spreads, commissions and execution differ between brokers and affect results.

Why check drawdown and not only win rate?

Hedge strategies can have a high win rate, but a single adverse move can cause a large drawdown. Review the live account's drawdown and open positions before you buy.

Is the license code itself enough to restrict account use?

Account restriction must be implemented in the EA's licensing logic. Website order collection and email delivery alone do not technically enforce a one-account license.
